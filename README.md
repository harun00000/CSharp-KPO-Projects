# ВышBuild

Сервис для приёма домашних работ, сохранения файла, автоматической проверки и формирования отчёта

## Запуск

Из папки `hw3`:

```bash
docker compose up --build
```

Порты:

- Gateway - `6765`;
- Analyze - `6766`;
- Store - `6767`.

Swagger:

- `http://localhost:6765/swagger`;
- `http://localhost:6766/swagger`;
- `http://localhost:6767/swagger`.

Для остановки:

```bash
docker compose down
```

## Architecture

Используется микросервисная архитектура:

- `VyshBuild.Gateway` - единая точка входа для клиента;
- `VyshBuild.Store` - хранение файлов и `Artifact`;
- `VyshBuild.Analyze` - анализ и хранение `Report`.

Такое разделение позволяет не смешивать хранение файлов, проверку и работу с клиентскими запросами в одном сервисе

Сервисы взаимодействуют синхронно по HTTP, данные между ними передаются в JSON

## User flow

### Сдача работы

(1-й сценарий) Студент отправляет имя, номер задания и файл через:

```text
POST /submissions
```

После этого:

```text
Client
-> Gateway
-> Store
-> Artifact
-> Submission
-> Analyze
-> Report
-> Client
```

Файл сохраняется в Store, Gateway фиксирует `Submission`, после чего синхронно запускается анализ и создаётся `Report`

### Получение отчётов

(2-й сценарий) Преподаватель получает отчёты по заданию через Gateway:

```text
GET /assignments/{assignmentId}/reports
```

Gateway запрашивает данные у Analyze и возвращает список отчётов по всем сдачам этого задания

## Технические сценарии обмена между сервисами

При сдаче работы Gateway последовательно вызывает:

```text
Gateway -> Store -> Analyze
```

Store возвращает данные об `Artifact`, после чего Gateway передаёт данные о сдаче в Analyze

Если Store или Analyze недоступен либо возвращает неуспешный HTTP-ответ:(, Gateway возвращает ошибку `503`

## Проверка на сборку

Вместо реальной компиляции используются правила:

- файл не должен быть пустым
- файл должен иметь расширение `.zip`

Если оба условия выполнены, проверка считается успешной

Такой вариант выбран как простая проверка файла без запуска пользовательского кода

## Визуализация

Для отчётов по заданию сделана простая HTML-таблица со статусом проверки, результатом и деталями каждой сдачи

(доступна через):

```text
GET /assignments/{assignmentId}/reports/view
```
